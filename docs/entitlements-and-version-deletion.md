# 分程序续期、Beta 通行证与旧版本删除

2026-10-28，加载器与服务端 1.0.5。

## 激活规则

- 一个账号分别保存每个稳定程序的到期时间。单程序、多程序、全部程序码可交叉兑换；不再要求和账号原来的分类或 Beta 标记相同。
- 每个目标程序独立按 `max(该程序原到期时间, 服务器现在时间) + 激活码时长` 续期；未购买的程序从现在开始。其他程序保持原来的时间。
- AB 各 30 天，再兑换 A 30 天，变成 A 60 天、B 30 天；A 30 天再兑换 B 30 天，变成同账号下 A、B 各 30 天。
- 全部程序码相当于为**兑换时已登记的每个稳定程序**各兑换一次相同时长，不是所有程序共用一个计时器。以后新增程序不会自动获得过去兑换的时长。
- 永久码只将目标程序升级为永久。已有永久时长不减少；仍可购买其他程序。若兑换没有增加任何时长或权限，则拒绝兑换且不消耗激活码。
- 已兑换码及其使用者、时间继续保留；它们不是需要切换的授权套餐，实际权限来自各程序累计结果。

## Beta

后台程序范围新增「仅 Beta 通行证（不计时）」。这是账号上的通行资格，不赠送或延长稳定程序时间。重复兑换已有通行证不消耗激活码。

拥有 A 稳定版有效授权时可访问 A Beta；拥有 B 时可访问 B Beta；都有则都可访问。稳定版到期，其 Beta 同时不可下载、启动或继续心跳。续期稳定版后，Beta 自动恢复，无需重复购买通行证。只兑换通行证、尚无稳定授权的账号可以登录和继续兑换，但无法使用任何程序。

原有「允许访问 Beta 程序」勾选项仍表示稳定程序时长和通行证的组合码；需要只卖通行证时选择新增的范围。

## 兼容与管理

`users.json` 新增 `programExpiries`，值为程序 ID 到 UTC 到期时间的映射，`null` 表示该程序永久。整个字段缺失或为 `null` 时按旧账号范围和总到期时间读取，首次兑换或单独设置程序时间时转换；保留各原有程序剩余时长、密码和历史兑换记录。转换与激活码消费仍使用现有事务恢复记录，避免重复消费或重复加时。

`expiresAt` 保留为概览时间：有永久程序则为空，否则为最晚到期时间。无程序时为最小时间。具体下载、启动票据、票据兑换和运行心跳均按**对应程序**校验，不能用 B 的时长延长 A。

加载器选中程序时显示该程序倒计时及到期时间，Beta 显示对应稳定程序的时间。过期程序仍保留在库中供查看和续期，操作按钮不可用。后台可分别修改各程序时间；原来的总时间表单明确标记为「统一设置全部程序到期时间」。保存程序权限时保留仍授权程序各自的时间。

旧加载器能连接新服务端，但仍会显示账号概览时间；需更新加载器才能正确展示分程序时间。旧服务端不支持新规则。部署前应备份数据，再更新服务端和加载器。

## 删除旧版本

后台「程序与选项 → 版本状态」中，非当前推荐版本提供「删除旧版本」按钮和确认提示。操作要求管理员登录及 CSRF 校验，成功后记录审计。

删除移除该版本目录内的 ZIP、签名与清单；其他版本、其他程序和账号时间不受影响。已安装的被删版本也不能再获得启动授权，运行租约在后续心跳被拒绝。若需允许已安装用户继续使用，请使用「撤回下载」。

显式推荐指针指向的版本，以及自动回退后实际提供的当前版本，都受删除保护。要删这些版本，应先保存另一个可用版本为推荐。链接目录被拒绝；文件占用或权限错误会提示管理员重试。

## 本地验证

服务构建固定在 `.local/maintenance-check/server/`，加载器固定在 `.local/maintenance-check/client/`。测试可设置 `CHISPA_TEST_SERVER` 为该服务 DLL 的绝对路径，不改 `.local/current-server-build.txt`：

```powershell
$env:CHISPA_TEST_SERVER = Join-Path $PWD '.local/maintenance-check/server/Chispa.Server.dll'
python tests/activation_matrix.py
python tests/entitlement_matrix.py
python tests/version_matrix.py
python tests/admin_matrix.py
```

界面测试 `Chispa.Smoke.dll --preview` 新增选中程序的已到期、有效和永久状态检查；设置 `CHISPA_UI_OUTPUT` 可将截图保存到 `.local/maintenance-check/ui/`。测试账号、签名测试密钥、端口及程序包均独立，测试临时数据在 `finally` 中清理。
