# 加载器 1.0.3：窗口按钮、账户信息与文字裁切

本次仅调整加载器界面及 DPI 处理。

- 关闭、最小化和所有页面共用同一个主窗口玻璃表面，主矩形包住顶部按钮。移除上一版独立的矩形外顶栏和页面重复边框。
- 账户区域使用独立卡片，用户名、剩余时间、到期时间分别占一行；操作按钮放在卡片右侧，不覆盖文字。日期显示运行电脑的本地时间。
- 标签统一采用缓冲绘制，测量和绘制使用一致的文字标志及留白。局部重绘保留裁剪区；没有完整行高时不画半行字。补足注册页标题高度和分数缩放时字体行高的舍入余量。
- 原生输入框按实际字体高度垂直居中。启用 PerMonitorV2，使窗口支持显示器 DPI 变化，更新圆角区域；绘制装饰后恢复图形变换，避免变换影响后续窗口边框。

验证：

- 加载器及测试工程编译通过，零警告、零错误。
- 账户三行都位于卡片内，互不相交，且与右侧操作按钮不相交；最小化和关闭按钮位于主矩形内部。
- 可见标签按真实字体测量高度；输入框高度不低于其首选字体高度。注册、登录、程序库与续费页预览已检查。
- 将账户文字分成每条 5 像素的窄带分别重画，与整块绘制逐像素比较一致，用来检查局部重绘留下旧字或截断文字的问题。
- 100%、125%、150%、200% 模拟检查通过。高 DPI 检查给测试窗口发送 DPI 变化消息，并同步放大显式字体，避免只放大控件边界而漏掉字体裁切。这是测试窗口内的模拟，没有修改 Windows 显示设置，也不等同于真实多显示器切换验收。
- 原有后台刷新检查通过：按钮状态不切换、不重绘，未变化的卡片不重建。安装、签名、启动授权及后台账户综合 smoke 通过。
- 尝试通过 computer-use 检查实际窗口时，窗口抓图两次超时（`FrameArrived timed out` / `window capture timed out`）；交付的截图来自加载器自身渲染。
