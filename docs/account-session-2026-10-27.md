# 账户时间、加载器启动和运行到期退出

日期：2026-10-27。涉及 loader 与 wardogs chispa 两个仓库。

## 用户可见行为

- 账户授权过期后仍可用正确密码登录加载器，查看账户和程序库。下载和启动仍要求有效授权。
- 加载器右上角显示用户名、每秒更新的剩余时间和带时区的实际到期时间；永久账户明确显示永久。账户信息在同步程序时重新读取，自动同步间隔为一分钟。
- 续期后点击“同步程序”即可恢复下载和启动，无须退出后重登。
- 从加载器启动时用一次性票据接续登录，主程序不再要求重复输入账号密码。票据仍由当前 Windows 用户的 DPAPI 加密；只把文件绝对路径作为参数传递，用户名密码和票据正文不进入命令行。
- 主菜单左下角保留运行状态，并显示账户用户名和授权到期时间。菜单日期使用运行电脑的本地时间，悬停有时区说明。
- 已知账户到期时间会限制运行租约的截止时间。即使断网或心跳请求阻塞，也有独立计时线程撤销运行权限并请求正常退出；等待 DMA、等待游戏时也会检查授权。

## 实现与兼容

服务端 `POST /api/v1/session` 将密码认证与订阅是否有效分开；新增 `GET /api/v1/session` 返回 `username`、`accountExpiresAt`、`serverTime`。原有 `expiresAt` 仍指加载器登录会话的 12 小时有效期，不能用来显示订阅时间。

账户信息和程序列表允许过期订阅访问；版本、安装包、启动清单、启动票据仍走有效订阅检查。删除账号、修改密码、退出登录继续撤销会话。一次启动失败不会销毁过期账户的程序库会话。

租约签发与心跳都返回 `accountExpiresAt`，且 `leaseExpiresAt = min(租约截止时间, 账户截止时间)`。主程序使用服务端时间差与单调计时，计算截止时间时扣除等待响应的时间，避免改系统时间或网络延迟延长授权。管理员运行中修改期限或撤销权限，联网时仍在下一个心跳生效（默认最多两分钟）；断网时按已取得租约和已知账户期限停止。

启动交接采用每次唯一的 `ticket-<程序>-<随机值>.bin`，通过 `--chispa-ticket <绝对路径>` 指定。UIAccess 重启保留命令行。兼容旧加载器的固定路径读取；显式指定的票据无效时报告交接失败，不再悄悄跳到密码提示。加载器和主程序仍需运行在同一个 Windows 用户身份下，DPAPI 不跨 Windows 账户解密。

心跳和截止时间线程通过互斥锁保护授权状态；退出标志改为原子变量，避免跨线程数据竞争。到期回调走已有退出流程，主程序的异常和早退路径也会清理授权线程。
