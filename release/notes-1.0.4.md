客户端和独立服务端 1.0.4。

- 客户端默认请求管理员权限，确认 Windows UAC 后启动。
- 注册使用邮箱格式账号、密码及一次性激活码；支持兑换续费。
- 后台支持生成、下载和作废激活码。
- 显示账户剩余时间及到期时间，修复窗口按钮、文字裁切和刷新闪烁。
- 加载器通过受保护票据启动软件，服务端持续检查授权。

下载 `Chispa.Launcher.exe` 即可使用客户端。服务端下载并解压
`Chispa.Server-1.0.4-win-x64.zip`，自带 .NET 运行时，按包内 README 初始化管理员。
升级已有服务时先备份数据，再指向原数据目录。

服务端包不含真实账户、激活码记录、管理员凭据或签名私钥。
`SHA256SUMS.txt` 提供两个成品的校验值。

软件 1.2.4 在独立的 Wardogs 仓库发布。源码、清理及构建方法见仓库 README。
